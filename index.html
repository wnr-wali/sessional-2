Q1

STEP 2 K-Map Simplification (to find MUX inputs)

We will use a 4×1 MUX. Since MUX has 2 select lines, we choose D and C as select lines (S1=D, S0=C). The MUX inputs I0, I1, I2, I3 become functions of the remaining variables A and B.

4×1 MUX structure: S1=D (MSB), S0=C (LSB) → selects one of I0, I1, I2, I3
I0 → when D=0, C=0 | I1 → when D=0, C=1 | I2 → when D=1, C=0 | I3 → when D=1, C=1
1

When D=0, C=0 (I0): Look at rows 0000,0010,0100 — wait, D=0,C=0 means rows DCBA: 0000,0010 → Y=0,0,0; 0001→Y=0; 0011→Y=1.
From table rows 1-4 (D=0,C=0): Y=0,0,0,1 → Y=1 only when A=1,B=1
I0 = A·B

2

When D=0, C=1 (I1): From table rows 5-8 (D=0,C=1): Y=1,1,1,1 → always 1 regardless of A,B
I1 = 1

3

When D=1, C=0 (I2): From table rows 9-12 (D=1,C=0): Y=0,0,0,0 → always 0
I2 = 0

4

When D=1, C=1 (I3): From table rows 13-16 (D=1,C=1): Y=0,1,0,1 → Y=1 only when A=1
I3 = A

STEP 3 4×1 MUX Implementation
Final MUX Configuration
Select Lines: S1 = D (Maintenance), S0 = C (VIP)
I0 = A·B (AND gate: slot available AND valid ticket)
I1 = 1 (constant HIGH — VIP always allowed in normal mode)
I2 = 0 (constant LOW — maintenance, non-VIP blocked)
I3 = A (slot available — maintenance VIP needs slot)
Output: Y = gate opens

Q2(a)
Design x+5 (if S=1) and x−5 (if S=0) for unsigned 5-bit number x, using Full Adders and minimum extra logic.
7 Marks
KEY IDEA The Trick — Add/Subtract Using 2's Complement
Core insight: x + 5 and x − 5 can both be done with one adder!

• x + 5: Add 00101 (5 in binary) to x
• x − 5: x − 5 = x + (−5) = x + (2's complement of 5)
   2's complement of 00101 = 11011 (i.e., flip bits + add 1)

So we need: x + B_in where B_in is either 00101 (S=1) or 11011 (S=0)
1

Represent 5 as binary: 5 = 0 0 1 0 1
Its 1's complement (flip): 1 1 0 1 0
2's complement (flip+1): 1 1 0 1 1 = −5 in two's complement

2

What changes between +5 and −5?
+5 = 0 0 1 0 1
−5 = 1 1 0 1 1
Notice: −5 = bitwise NOT of +5 with Cin=1. This is exactly 2's complement!

3

Controlled inversion: Use XOR gates to optionally invert each bit of 5 (00101).
If S=1 (add): XOR output = bit itself (00101)
If S=0 (subtract): XOR output = NOT bit (11010), and set Cin=1 → giving 11011

4

Cin of adder: Cin = S' (when subtracting, Cin=1 to complete 2's complement)

STEP 2 Labelled Block Diagram
x ± 5 Circuit using 5-bit Full Adder
Summary of Circuit
Constant 5 = 0 0 1 0 1
XOR each bit of 5 with S':
 • If S=1: S'=0 → XOR passes bits unchanged → B = 00101
 • If S=0: S'=1 → XOR inverts bits → B = 11010, Cin=1 → 11011 = two's complement of 5
Cin of FA₀ = S'
Result = x + B + Cin = x+5 (S=1) or x−5 (S=0)
Q2(b)

Inputs: A1A0 (2-bit, 0-3) and B1B0 (2-bit, 0-3). Output: F3F2F1F0 = A × B (max = 3×3=9, fits in 4 bits)

STEP 2 Extract Minterm Lists for Each Output
Minterm Lists
F3 = Σm(15)  → only m15 is 1
F2 = Σm(10, 11, 14, 15)  → m10, m11, m14, m15 are 1
F1 = Σm(6, 7, 9, 11, 13, 14)  → m6,m7,m9,m11,m13,m14 are 1
F0 = Σm(5, 7, 13, 15)  → m5, m7, m13, m15 are 1
Why decoder? A 4-to-16 decoder with inputs A1A0B1B0 activates exactly ONE output line (the minterm) at a time. Each output Dm corresponds to minterm m. So we simply OR together the required decoder outputs for each F!
